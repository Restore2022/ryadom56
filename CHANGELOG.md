## [0.11.0+12] — 2026-08-08 — MVP-2

### Афиша / события
- Модель `Event`, API `/api/events` (публичный список/деталь, CRUD для editor/admin)
- Админка: раздел «Афиша» — создание, правка, скрытие, удаление
- Приложение: вкладка «Афиша» (Скоро / Прошедшие / Все), карточка события, карта по адресу
- Сиды: несколько примеров событий района

### Транспорт
- Модель `TransportRoute`, API `/api/transport`
- Админка: раздел «Транспорт» — маршруты и текст расписания
- Приложение: в справочнике сегмент «Места | Транспорт», экран маршрута с «Обновлено»
- Сиды: 4 маршрута (Сакмара — Оренбург и др.)

### Прочее
- Сводка админки: счётчики событий и маршрутов
- README обновлён под MVP-2

## [0.10.0+11] — 2026-08-08

### Пользовательское приложение
- Удаление черновиков / отклонённых / архивных объявлений
- «Мои объявления»: вкладки по статусам и счётчик активных `N/5`
- Поделиться объявлением (системный share)
- SMS и WhatsApp после показа телефона
- Форма создания: цена скрыта для «Отдам», телефонная клавиатура, проверка номера
- Автосохранение черновика при выходе + toast
- Уведомления: относительное время
- Подтверждения: выход из аккаунта, очистка истории просмотров

### Админка
- Жалобы: модалка ответа, статусы по-русски, подтверждение отклонения
- Массовая модерация: подтверждение approve/reject
- Фильтры модерации: автофлаг, населённый пункт, объявления автора (`authorId`)
- Пользователи → «Объявления»; подтверждение выдачи роли staff
- Справочник: фильтры опубликовано / НП
- Раздел «Правовое» — редактирование документов
- Скачивание бэкапа SQLite с дашборда (только admin)

### Backend / безопасность
- `DELETE /listings/{id}`, `GET /listings/mine/stats`
- Rate limit: регистрация, логин, создание объявлений, жалобы
- Проверка magic-bytes у загружаемых изображений
- `PATCH /legal/{slug}`, `GET /admin/backup`
- Фильтры админ-ленты: `auto_flagged`, `settlement_id`, `author_id`
- Цена объявления `>= 0`
