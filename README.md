# Рядом56

Локальный MVP сервиса для Сакмарского района Оренбургской области и Оренбурга:
объявления/рынок, справочник, веб-админка, Android (Flutter).

## Состав

| Папка | Что внутри |
|-------|------------|
| `backend/` | FastAPI + SQLite |
| `admin/` | React-админка (Vite) |
| `mobile/` | Flutter-приложение (Android) |

## Быстрый старт (локально)

### 1. API

```bat
cd backend
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

- Документация API: http://127.0.0.1:8000/docs
- Админ по умолчанию: `admin@ryadom56.ru` / `admin123`

### 2. Админка

```bat
cd admin
npm install
npm run dev
```

Откроется http://127.0.0.1:5173

### 3. Android (Flutter)

Нужен установленный [Flutter SDK](https://docs.flutter.dev/get-started/install/windows).

```bat
cd mobile
flutter create . --project-name ryadom56 --org ru.ryadom56
flutter pub get
flutter run
```

> `flutter create .` один раз дописывает android/ios-обвязку к уже готовому `lib/`.

**API URL в эмуляторе:** `http://10.0.2.2:8000/api` (уже в коде).  
**На реальном телефоне:** укажите IP вашего ПК в LAN (в `lib/main.dart` / SharedPreferences `api_base`).

## Что уже есть (MVP-1)

- Регистрация: имя, email, пароль, телефон (опционально), населённый пункт, галочки соглашений
- 47 населённых пунктов Сакмарского района + Оренбург (две «Марьевки» разделены по сельсоветам)
- Объявления с модерацией (товары, услуги, работа, аренда, отдам, потеряшки)
- Справочник (школы, больницы, магазины и т.д.)
- Админка: сводка, модерация, справочник, роли пользователей (admin / moderator / editor)
- Юридические тексты: соглашение, политика, правила объявлений (`/api/legal`)
