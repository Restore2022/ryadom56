Частые вопросы

Это бесплатно?

Да. Сервис бесплатный на старте. Рекламы в приложении нет.

Есть версия для айфона?

Пока только Андроид (Android). Для айфона сделаем позже.

Нужна регистрация, чтобы смотреть ленту?

Нет. Гостем можно листать объявления. Писать в чат, звонить и подавать объявления — после входа.

Почему не в магазине приложений?

Пока ставите с этого сайта. Если телефон покажет предупреждение — так бывает у приложений не из магазина, можно продолжить.

Это не вирус?

Нет. Файл качайте только с legac.ru. Жёлтый экран Google бывает у любого приложения не из магазина. Нажмите «всё равно установить» — так и задумано.

Приложение уже стоит. Снова скачивать?

Нет. Откройте Рядом56 на телефоне — если вышла новая версия, приложение само предложит обновиться.

Какие населённые пункты есть?

Сёла и посёлки Сакмарского района и Оренбург. Две Марьевки указаны отдельно, чтобы не перепутать.

Можно звонить из приложения?

Да. По объявлению звоните прямо в Рядом56 — обычный разговор, как по телефону.

Как с вами связаться?
