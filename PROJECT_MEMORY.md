## Что это

Бесплатный на старте сервис для **Сакмарского района** (Оренбургская область) с заделом на **Оренбург**.

- Автор живёт в районе. Цель: соцвклад → портфолио → позже монетизация. Бюджет небольшой.
- Сейчас: **только Android**, **только русский**. iOS позже (Flutter).
- Раздача APK вручную / ссылка с сервера. В сторы: **сначала RuStore, не Google Play**.
- Домен: **legac.ru** (REG.RU) на FirstVDS, HTTPS Let’s Encrypt на `legac.ru` и `www.legac.ru`.
- Юр. тексты (соглашение / политика / правила) нужны. Регистрация без подтверждения почты/SMS.

Название: **Рядом56**. Пакет: `ru.ryadom56.ryadom56`.

Стек: Flutter Android · FastAPI · SQLite · React-админка (Vite).

## Как собирать APK (обязательно)

**Не собирать Flutter/Gradle локально**, если можно через GitHub — чаты регулярно обрывались на JDK/Gradle/Metaspace.

1. Закоммитить нужный `mobile/` (включая `google-services.json`).
2. `git push origin main` → Actions «Build Android APK».
3. `gh run download <id> -n ryadom56-apk`.
4. Положить в `mobile/apk/app-release.apk`, копия на рабочий стол, `upload_apk.py`.
5. Версия в `pubspec.yaml` (`x.y.z+build`) **должна совпасть** с `deploy/upload_apk.py` и записью `AppUpdate` на сервере.

CI сам поднимает память Gradle (локальный `gradle.properties` специально маленький: `-Xmx640m`, иначе Windows замирает). **Не возвращать** `org.gradle.java.home=E:\\android\\jdk-17` — CI от этого падает.

Последняя **залитая** сборка: **0.25.0+39** (15.08.2026). API: `https://legac.ru/api`. Скачать: `https://legac.ru/api/app/apk`. Старый `:8080` оставлен для OTA с предыдущих APK.

## Сделано (по чатам 5–13 авг 2026)

### Продукт MVP-1
- Регистрация: имя, email, пароль, телефон опционально, село из списка, галочки юр. текстов
- ~47 НП Сакмарского района + Оренбург (две Марьевки разделены)
- Объявления + модерация, категории, фильтры, детальная карточка, тёмная тема
- «Мои»: снять с причиной, повторно опубликовать, правка → снова модерация
- Жалобы на объявления и на контакты справочника; очередь в админке
- Избранное объявлений и организаций
- Профиль: имя / телефон / село / пароль
- Лимит 5 активных объявлений
- Скрытие телефона до «Показать / Позвонить»
- Гостевой просмотр ленты; писать/звонить — после входа
- Пагинация ленты, сжатие фото, камера+галерея, до 5 фото
- In-app «уведомления» (одобрено/отклонено) + бейджи
- PIN 5 цифр после регистрации; старые пользователи тоже обязаны поставить; кнопка «пропустить PIN» убрана (это защита входа в приложение)
- Глазик пароля на входе/регистрации
- Адаптив альбом/планшет (боковое меню)
- Кнопка «наверх» в длинных списках
- Чаты 1-на-1 по объявлению (не общий тред на всех)
- Ошибки сети без слов «API»: интернет или связь с сервером
- OTA-обновление APK с сервера; один signing key чтобы не плодить иконки
- Device fingerprint: IP, модель телефона — в карточке пользователя админки

### Справочник / афиша / транспорт / новости (MVP-2 по факту уже в приложении)
- Справочник: поиск, звонок, часы, жалобы на контакты, статистика открытий по сёлам
- Афиша из профиля (не вкладка снизу); транспорт во вкладках как у ленты; фильтры по сёлам; «МТ» = междугородний/межрайонный тип маршрута
- Новости района + срочный баннер (не раздувать шапку главной)
- Сбор школ района: `deploy/sakmarsky_schools.json` (официальный сайт + правки координат)

### Админка
- Сводка, модерация, справочник (модалка «добавить»), пользователи (редактирование, разблокировка)
- Роли: admin / moderator / editor
- Лог действий модерации, шаблоны причин отклонения, массовые действия
- Чекбоксы приведены к нормальному виду; модерация уже одобренных не светит approve/reject
- Просмотр фото объявления в модалке с листанием
- Контроль чатов (модерация мусора)
- Тёмная тема

### Push / аккаунт (авг 13–14)
- Клиент FCM + `google-services.json`
- Сервер HTTP v1 + service account на VPS
- Пуши: сообщение в чате, модерация объявления, срочный алерт района
- Сессии устройств (`/auth/sessions`, экран в приложении)
- Восстановление пароля: экран + API `/auth/forgot-password` и `/auth/reset-password`
- **SMTP задан на VPS** (ящик `info@legac.ru` через REG.RU hosting). Письма сброса пароля должны уходить.
- Админка: пуш **конкретному пользователю** из карточки (Пользователи → изменить). Пишет в колокольчик + FCM на все его устройства. APK пересобирать не нужно.

### Навигация / профиль / вход (авг 15)
- Нижний бар: **Лента | Чаты | Транспорт | Места | Профиль** (профиль справа). Афиша ушла из табов в пункт профиля.
- «+» подать объявление только на вкладке ленты (FAB), не на остальных экранах.
- Колокольчик уведомлений в верхней шапке, не внутри профиля.
- Фото профиля: `POST/DELETE /auth/me/avatar`, колонка `users.avatar_path`, файлы в `data/uploads/avatars`.
- Экран разблокировки: сначала отпечаток/лицо (если включено), PIN запасной. PIN никуда не делся.

### Доверие / объявления (авг 15, APK 0.24)
- Шаблоны «Отдам», «Ищу работу», «Потерял…» в форме подачи; в пустой ленте категории — пример текста и кнопка «Подать такое».
- Локальный черновик (текст + пути фото): не пропадает, если закрыть экран или убить приложение на половине пути. Серверный черновик как раньше.
- Срок публикации 30 или 60 дней, в ленте просроченное снимается само. «Продлить» у автора: для живого объявления двигает дату, для снятого по сроку возвращает в ленту без повторной модерации.
- Гостевой баннер на чатах, избранном и карточке: ленту смотреть можно, конверсия в аккаунт — «войти / создать».
- Жалоба на человека (не только на карточку). Автобан после 3 жалоб на человека или 5 на объявления. В админке вкладка «Люди» + снятие блока статусом «Активен» (причина бана видна).
- Лимит 50 сообщений в сутки на аккаунт, без капчи. Телефон покупателю не светится, пока автор не ответил в чате.
- Вход по биометрии: экран больше не съезжает влево на первом показе (длинная кнопка + масштаб всего экрана).

### Рядом / пагинация / сбои (авг 15, APK 0.23)
- Чип «Рядом»: сортировка объявлений и мест по GPS или по выбранному селу (координаты всех 48 НП в БД). Не фильтрует только своё село — сортирует весь список по расстоянию, в карточке `distance_km`.
- Тёмная тема: чипы и карточки с более светлой заливкой и заметной рамкой.
- Сбои с телефонов: `POST /api/client-errors` → админка «Сбои приложения».
- Новости, афиша и транспорт отдают `{items,total,limit,offset}` как места; в приложении подгрузка «Ещё».
- Публичные юр. страницы без логина: `/legal/privacy`, `/legal/terms`, `/legal/listing_rules`.

### Время (авг 15)
- API отдаёт datetime в UTC с поясом (`Z` / `+00:00`). Раньше SQLite слал naive ISO, телефон думал что это уже местное → «5 часов назад» (Оренбург UTC+5).
- Текущий APK это подхватит без пересборки (уже делает `toLocal()`).
- В коде приложения общий `parseApiTime`: naive ISO тоже считать UTC. Попадёт в следующую сборку APK.

### Сервер
- nginx, uvicorn, порт **8080 в UFW** (без этого приложение «не видело» сервер)
- `client_max_body_size` — иначе загрузка APK **413**
- Демо-контент (`seed_demo_content`) для продакшена выключен
- **15.08.2026:** с VPS снята автошкола (`avtoskolanewadmin`: nginx :80, API :8000, Telegram-бот, MySQL). MySQL выключен (Рядом56 на SQLite), UFW 3306 закрыт.
- **15.08.2026:** домен `legac.ru` + `www.legac.ru` на VPS, HTTPS Let’s Encrypt (до 13.11.2026, автопродление). Старый `:8080` оставлен для OTA со старых APK.
- **15.08.2026:** исходящая почта `info@legac.ru` через `mail.hosting.reg.ru:465`. A-записи `@` и `www` должны оставаться на VPS (`155.212.174.201`); MX/SPF/DKIM — на REG.RU. Не переключать A сайта на `31.31.197.102`, иначе отвалится HTTPS.
- **15.08.2026:** APK **0.25.0** ходит на `https://legac.ru/api` (сохранённый IP:8080 на телефоне сбрасывается).

## Ловушки (уже ловили)

- Локальный `flutter build` / Java 25 / `org.gradle.java.home` на `E:\` → зависание или красный CI.
- Маленький Metaspace + Firebase → `Metaspace` на GitHub; CI переписывает `jvmargs`.
- Версия APK ≠ `AppUpdate` в БД (как 0.22.0 метка на файле 0.21.0) — ломает OTA.
- Другой keystore → второе приложение рядом со старым.
- Закрытый UFW 8080 → «нет связи».
- nginx 413 на большой APK.
- Чаты сначала были общими на объявление — исправлено на 1-на-1.
- Списки обрезались снизу/справа — отступы под нижней панелью, горизонтальные чипы без жёсткой высоты 40.
- Главная: не возвращать огромный блок «район / новости» в шапку ленты.
- Не светить тестовые seed-данные на проде.
- Не коммитить `mobile/apk/*.apk` и `deploy/_hot_deploy_*.py` / `_check_*.py` без нужды.
- Посторонний GitHub «Instagram toolkit» (selsabil-webdev) — **не наш проект**, malware-лендинг; к Рядом56 отношения не имеет.
