## Что это

Бесплатный на старте сервис для **Сакмарского района** (Оренбургская область) с заделом на **Оренбург**.

- Автор живёт в районе. Цель: соцвклад → портфолио → позже монетизация. Бюджет небольшой.
- Сейчас: **только Android**, **только русский**. iOS позже (Flutter).
- Раздача APK вручную / ссылка с сервера. В сторы: **сначала RuStore, не Google Play**.
- Домен: **legac.ru** (REG.RU) на FirstVDS, HTTPS Let’s Encrypt на `legac.ru` и `www.legac.ru`.
- Юр. тексты (соглашение / политика / правила) нужны. Регистрация без подтверждения почты/SMS.

Название: **Рядом56**. Пакет: `ru.ryadom56.ryadom56`.

Стек: Flutter Android · FastAPI · SQLite · React-админка (Vite).

## Как собирать APK (обязательно)

**Не собирать Flutter/Gradle локально**, если можно через GitHub — чаты регулярно обрывались на JDK/Gradle/Metaspace.

1. Закоммитить нужный `mobile/` (включая `google-services.json`).
2. `git push origin main` → Actions «Build Android APK».
3. `gh run download <id> -n ryadom56-apk`.
4. Положить в `mobile/apk/app-release.apk`, копия на рабочий стол, `upload_apk.py`.
5. Версия в `pubspec.yaml` (`x.y.z+build`) **должна совпасть** с `deploy/upload_apk.py` и записью `AppUpdate` на сервере.

CI сам поднимает память Gradle (локальный `gradle.properties` специально маленький: `-Xmx640m`, иначе Windows замирает). **Не возвращать** `org.gradle.java.home=E:\\android\\jdk-17` — CI от этого падает.

Последняя **залитая на VPS** сборка: **0.31.0+45** (29.08.2026, GitHub run `33239875482`). OTA: `https://legac.ru/api/app/apk`. Файл на рабочем столе `ryadom56-0.31.0.apk`. На сервере свой **coturn** (UDP/TCP 3478 + UDP 49160–49220). API: `https://legac.ru/api`.

### Звонки в приложении (авг 26, APK 0.26)
- Голосовой звонок через интернет (WebRTC) из карточки объявления и из чата. Без видео, без записи разговора.
- Входящий: пуш + экран «ответить / сбросить». Если человек офлайн — запасной набор обычного номера (если телефон уже можно показывать).
- Админка → **Звонки**: кто кому, когда, статус, длительность, объявление.
- Медиа: сначала телефон↔телефон (STUN). Если сети режут P2P — **свой coturn** на VPS (`TURN_AUTH_SECRET` + `TURN_HOST` в `.env`, не в git). Cloudflare TURN отложили: для их «фри» просили американскую карту.
- Ловушка WS: `Uri(port: null)` на Dart даёт `wss://legac.ru:0` → HTTP 401, сокет не поднимается. Собирать URL строкой без нулевого порта. На nginx `location /api/calls/ws` нужен и на `:8080`, и на `legac.ru:443` (Upgrade + Authorization).
- Таймер разговора нельзя вешать через `const CallTicker(child: CallSessionScreen())` — Flutter не пересобирает const-ребёнка, секунды скачут пачками. Тикер должен быть внутри самого экрана звонка.
- Кто положил трубку: `ended_by_id` на звонке; в чате «Имя завершил звонок · мм:сс»; на экране у второго — та же фраза на 1.4 с.
- В чате после звонка видна плашка: пропущен / отклонён / отменён / кто завершил / длительность.

- Форма сайта: непредустановленная галочка согласия со ссылкой на политику. Политика 1.4 с разделами оператора, субъектов, действий, сроков, уничтожения, прав и защиты. В подвале: оператор — физлицо, ИНН/ОГРН организации не присвоены. На визитке «Андроид (Android)» рядом, одинаковым текстом.
- `www.legac.ru` → 301 на `https://legac.ru`. Статика визитки кэшируется 30 дней. На телефоне не грузится герой-скрин, шрифты урезаны, кадры установки — только после раскрытия. Бегунок сёл не дублирует все 48 названий (тошнота текста).

### Рядом / пагинация / сбои (авг 15, APK 0.23)
- Чип «Рядом»: сортировка объявлений и мест по GPS или по выбранному селу (координаты всех 48 НП в БД). Не фильтрует только своё село — сортирует весь список по расстоянию, в карточке `distance_km`.
- Тёмная тема: чипы и карточки с более светлой заливкой и заметной рамкой.
- Сбои с телефонов: `POST /api/client-errors` → админка «Сбои приложения».
- Новости, афиша и транспорт отдают `{items,total,limit,offset}` как места; в приложении подгрузка «Ещё».
- Публичные юр. страницы без логина: `/legal/privacy`, `/legal/terms`, `/legal/listing_rules`.

### Время (авг 15)
- API отдаёт datetime в UTC с поясом (`Z` / `+00:00`). Раньше SQLite слал naive ISO, телефон думал что это уже местное → «5 часов назад» (Оренбург UTC+5).
- Текущий APK это подхватит без пересборки (уже делает `toLocal()`).
- В коде приложения общий `parseApiTime`: naive ISO тоже считать UTC. Попадёт в следующую сборку APK.
- Карточка события: `formatEventWhen` — «15 сентября, 17:00–18:00». В исходниках Flutter уже есть; на сайте живое с `v=23`. В APK 0.30 ещё старый вывод (только начало) до следующей OTA.

- Демо-контент (`seed_demo_content`) для продакшена выключен

## Ловушки (уже ловили)

- Локальный `flutter build` / Java 25 / `org.gradle.java.home` на `E:\` → зависание или красный CI.
- Маленький Metaspace + Firebase → `Metaspace` на GitHub; CI переписывает `jvmargs`.
- Версия APK ≠ `AppUpdate` в БД (как 0.22.0 метка на файле 0.21.0) — ломает OTA.
- Другой keystore → второе приложение рядом со старым.
- Закрытый UFW 8080 → «нет связи».
- nginx 413 на большой APK.
- Чаты сначала были общими на объявление — исправлено на 1-на-1.
- Списки обрезались снизу/справа — отступы под нижней панелью, горизонтальные чипы без жёсткой высоты 40.
- Афиша: не `Flexible` на фильтры + `Expanded` на список (фильтры съедают половину экрана) и не `SegmentedButton` на узком телефоне. Один `CustomScrollView` + `ryadomChipRow`.
- Главная: не возвращать огромный блок «район / новости» в шапку ленты.
- Не светить тестовые seed-данные на проде.
- Не коммитить `mobile/apk/*.apk` и `deploy/_hot_deploy_*.py` / `_check_*.py` без нужды.
- Посторонний GitHub «Instagram toolkit» (selsabil-webdev) — **не наш проект**, malware-лендинг; к Рядом56 отношения не имеет.
- Не возвращать админку на корень `legac.ru` — там визитка. Сборка admin: `base: './'` (относительные ассеты). `deploy_site.py` не рестартит API и не трогает `/api/calls/ws`.
- `Uri(scheme: wss, port: null)` в Dart → `legac.ru:0` и HTTP 401 на сокете звонка. Собирать URL строкой без порта 0.
- Бэкапы nginx (`ryadom56.bak-*`) не оставлять в `sites-enabled`: конфликтуют `server_name`, патч `/api/calls/ws` попадает не в живой файл. Живой сайт — только симлинк на `sites-available/ryadom56`.
- `www.legac.ru` должен 301 на `https://legac.ru` (отдельный server). Не держать `www` в том же `server_name`, что и визитка — иначе редиректа нет.
- `dpkg --configure coturn` на этой Ubuntu зависает: вопрос про `/etc/turnserver.conf` (нужен `--force-confold`) и старт сервиса в postinst. Если пакет уже `install ok installed` — не крутить dpkg, а `systemctl enable --now coturn`.
- `apt-get autoremove --purge` снимает coturn, если пакет не помечен manual. После установки: `apt-mark manual coturn`. Ставить только `apt-get install -y -o Dpkg::Options::=--force-confold coturn`, секрет брать из существующего `.env`, **не** гонять `_setup_coturn.py` целиком — он может выписать новый `TURN_AUTH_SECRET` и сломать звонки на телефонах.
- systemd `MemoryMax=350M` у `ryadom56`: не качать весь APK через uvicorn в скрипте деплоя — сервис падает в 502. Файл проверять на диске (`PK` zip).
